    How it works

    1

    Trained from scratch

    Forward pass, backpropagation and the Adam optimizer were written by hand in NumPy, then trained on 55,000 handwritten digits (MNIST).

    2

    Compressed for the web

    Weights are stored as 8-bit integers with one scale per neuron, cutting the size by 4× with no loss in test accuracy (98.27% either way).

    3

    Runs in your browser

    About 40 lines of JavaScript repeat the same maths: multiply by the weights, add biases, apply ReLU, then softmax. Nothing is sent to a server.
