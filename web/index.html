How it was made

  1. Written by hand

    The forward pass, backpropagation and the Adam optimizer are my own NumPy code, checked against numerical gradients.

  2. Trained on many handwriting styles

    55,000 MNIST digits, plus generated digits in styles MNIST rarely contains, like a 1 with a long flag, a crossed 7 or a slashed 0.

  3. Shrunk for the web

    The weights are stored as 8-bit integers, making the model 4× smaller with the same accuracy.

  4. Run in your browser

    About 40 lines of JavaScript repeat the maths: multiply by the weights, add the biases, apply ReLU, then softmax. Nothing leaves your device.
